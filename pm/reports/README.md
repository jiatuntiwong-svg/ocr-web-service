# pm/reports/

Agent เขียนผลงานที่นี่ — ไฟล์ละ 1 งาน ตั้งชื่อตาม task ID เช่น `OCR-1.md`, `API-2.md`

รูปแบบขั้นต่ำ:

```markdown
# <ID> — <ชื่องาน>
Agent: <ชื่อ agent> | วันที่: <date> | สถานะ: done / blocked

## สิ่งที่ทำ
## ผลการทดสอบ (ระบุว่า test บน next dev หรือ npm run preview)
## ไฟล์ที่แก้
## ประเด็นที่ PM ต้องตัดสินใจ (ถ้ามี)
```
