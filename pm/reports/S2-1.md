## Config schema (delta from OCR-2)

`scripts/ocr-regression/cases/benchmark.json` introduces:

- Top-level `categories{}` map (label + description per category).
- Per-case `category`, `min_pass_rate`, `guards_issue`, `skip_if_missing`, `notes`, `template` (interpolated from env).
- Field rename: `assertion.expect` → `expected` (for the benchmark shape only; legacy `expect` remains valid for `ocr-2.json` / `ocr-6b.json`).
- New assertion type: `table_structure` — accepts `rows: string[][]` and matches with whitespace tolerance.

Runner auto-detects benchmark vs legacy shape (`!!categories && cases[0].category`) — nothing else has to change.

## Runner extensions

- CLI: `--config`, `--category`, `--case` (comma-sep), `--runs`, `--fail-under`, `--log silent|normal|verbose`, `--dry-run`, `--help`.
- Scoring output: per-case rate, per-category mean rate + meets-threshold ratio, pooled overall score.
- Delta: reads the newest previous `_summary-*.json` and reports Δ vs current per category + overall.
- Markdown: writes `pm/reports/OCR-2-latest.md` (30-second read).
- Skip semantics: unset template env var → category cases skipped (not failed); `skip_if_missing: true` on a case skips the case when the fixture file is absent. Both flow into the ⏭ column of the report.
- CI hook: `--fail-under 0.7` exits non-zero when overall < 0.7.

## Fixture generator extension

`generate-fixtures.mjs` now recurses category subfolders + supports `--category` filter + `--dry-run`. Landscape category is rendered A4 landscape automatically (matches the real production letterbox path).

### Harness / assertion fixes applied during first-run

1. **Harness stage order** — v2 shows TemplatePickerPanel only after upload. Reordered `runOcrCase` to upload first, then Next→Fields→Next→Run→Start extract. (`scripts/ocr-e2e/harness.mjs`)
2. **Scraper via JSON tab** — v2 field cards had `⋯` overflow buttons that DOM heuristics kept scraping. New scraper clicks "JSON raw" tab, parses `<pre>` textContent, returns `parsed[field].value` (or `JSON.stringify` for tables/arrays). Deterministic.
3. **`multiline` assertion** — normalize whitespace (`\s+` → single space) before comparing so line-wrap variance doesn't false-negative; still verifies separation between adjacent expected lines.
4. **`table_structure` row-object shape** — AI returns row-header tables as `[{Header:"Value"}, …]`, not `[[Header, Value], …]`. When expected row length is 2 and observed row is a single-key object, treat `[key, value]` as the cells. `Object.values()` fallback stays for column tables.
5. **Assertion crash guard** — wrap `assertionFn` in try/catch so one bad shape can't kill the suite mid-run.

### Real failures worth investigating

- **`landscape-a4-widefield`** (0/3, real regression): AI returns `ศูนย์**บริการ**โลหิตและพลาสมา` — omits the word `รับบริจาค` from the expected `ศูนย์**รับบริจาค**โลหิตและพลาสมา`. Deterministic across 3 runs = not variance; hint redraw didn't help (crop pass returns the same misread). Symbolic of an under-specified Thai extraction prompt → **hands S2-2 (prompt profiles) a concrete evidence-based work item**.
- **`dense-22-row-table` run 1 timeout**: `page.setInputFiles` waited 30s for `input[type="file"]` locator. Not a content issue — v2 flow first-render race; runs 2-3 passed cleanly. If flaky in future runs, add an explicit `await page.waitForSelector('input[type="file"]', { state: "attached" })` before `setInputFiles`.
