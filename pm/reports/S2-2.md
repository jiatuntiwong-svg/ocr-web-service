### Landscape verdict

`landscape-a4-widefield` still misses "รับบริจาค" 3/3 despite the explicit anti-example in `SHARED_RULES_TH`. AI returns `ศูนย์บริการโลหิตและพลาสมา` with `corrections: []` (does not report this as a correction).

Fixture HTML confirmed correct — the phrase `ศูนย์รับบริจาคโลหิตและพลาสมา` is present. So this is a vision-side issue at inference time, not a prompt gap. The prompt rule is being read but not applied — the model doesn't perceive the "รับบริจาค" glyph cluster in the crop.

**Not a prompt-profile problem.** Handoff to a separate follow-up: DPI bump on crop rendering, retry with temp 0.6 (OCR-3), or a small resize + re-crop pass.
