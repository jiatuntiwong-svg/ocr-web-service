เฟสสิ่งที่ส่งเงื่อนไข
UI-4b ทุกอย่างใน mockup v1 (stepper, two-zone, advanced expander, overflow menu) + result tabs (Fields/JSON/แก้คำ — ข้อมูลมีอยู่แล้วใน raw_json) + โครง page strip แบบ static (ไม่มี per-page status) หลัง flag ocrWorkspaceV2, ห้ามลบ layout เก่า
S2-3 Keyboard review mode — additive, ไม่แตะ layout หลัง UI-4b ขึ้น preview
S2-5 Page strip + per-page status (รองรับ per-page parallel S2-4) และ click-sync overlay Overlay ใช้พิกัด bbox → ต้องผ่านบทเรียน OCR-6c: วาดบน canvas raster ตัวเดียวกับ upload เท่านั้น; per-page status รอ S2-4
เฟสหลัง Compare เป็น mode tab — restructure ใหญ่ ต้องอัปเดต UX_DESIGN_BRIEF ก่อน UI ideas §3 ข้อ 4 (effort ใหญ่สุด)
⚠️ ย้ำจาก v1:

implementation notes ทั้งหมดของ v1 ยังใช้บังคับ (hint overlay ห้าม remount, batch = top-level mode, error states ใน stepper, feature flag, currentStage state, i18n ทุก string) — v2 เพิ่มข้อเดียว: overlay กรอบสีของ field ต้องใช้ bbox จาก raw_json ที่วาดบน canvas เดียวกับภาพที่ส่ง AI (พิกัดชุดเดียวกัน) — ห้ามคำนวณจาก preview คนละตัวเด็ดขาด (บทเรียน OCR-6c)
