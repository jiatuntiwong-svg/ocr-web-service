บันทึกการเปลี่ยนแปลง v2 → v3

  • ตัด Compare mode tab ออก — Compare ยังเป็นหน้าแยกตามเดิม (ตัดสินใจ 2026-07-08); การรวม workspace เลื่อนไม่มีกำหนด
  • Overlay controls UI-4b — ปุ่ม 👁 เปิด/ปิดทั้ง layer + segmented switch ▢ กรอบ / ▁ เส้นใต้ (reuse pattern highlight ของ Compare — implementer ดู highlight style ที่ CompareWorkspace ใช้อยู่)
  • Tab JSON raw UI-4b — render จาก raw_json ที่มีแล้ว ไม่ต้องมี backend ใหม่ · มี copy/download
  • Tab แก้คำ UI-4b — diff เดิม→ใหม่ + ปุ่ม ยอมรับ/ใช้ค่าเดิม/ดูตำแหน่ง (ปุ่ม "ใช้ค่าเดิม" = แก้ value กลับ ฝั่ง client เท่านั้น; การเก็บเป็น rulebase คือเฟสหลัง)
  • ครบ 6 step — step 2 (เลือกหน้าแบบ grid + คำแนะนำเรื่องฟอร์มปนกัน), step 4 (สถานะกำลังรัน + ยกเลิก), step 6 (export hub + เตือน confidence ต่ำ + สรุปงาน + "เอกสารถัดไป")
  • Implementation notes ของ v1 ทั้งหมดยังบังคับใช้ (flag ocrWorkspaceV2, currentStage state, hint overlay ห้าม remount, i18n, error states ใน stepper)
